Cómo usar el API.

Esta API ofrece datos en formato JSON sobre las provincias, cantones y distritos de Costa Rica. Sin API key, con CORS abierto y respuestas cacheadas.

Endpoints disponibles

1. Provincias

Devuelve todas las provincias en formato JSON:

GET /provincias.json

Ejemplo de respuesta:

{
  "1": "San José",
  "2": "Alajuela",
  "3": "Cartago",
  "4": "Heredia",
  "5": "Guanacaste",
  "6": "Puntarenas",
  "7": "Limón"
}

2. Cantones

Devuelve los cantones de una provincia (provinciaId del 1 al 7):

GET /provincia/:provinciaId/cantones.json

Ejemplo de respuesta para provinciaId=1:

{
  "1": "Central",
  "2": "Escazú",
  "3": "Desamparados",
  ...
}

Respuesta completa incluye los 84 cantones del país según la provincia consultada.

3. Distritos

Devuelve los distritos de un cantón (cantonId dentro de la provincia):

GET /provincia/:provinciaId/canton/:cantonId/distritos.json

Ejemplo de respuesta para provinciaId=1 y cantonId=1:

{
  "1": "Carmen",
  "2": "Merced",
  "3": "Hospital",
  ...
}

El código postal se forma como provincia + cantón + distrito: por ejemplo, Carmen (1/1/1) es 10101.
