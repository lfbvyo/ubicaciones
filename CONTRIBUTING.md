# Contribuir a Ubicaciones de Costa Rica

Gracias por ayudar a mantener este proyecto abierto y actualizado.

## Flujo

1. Creá un fork del repositorio.
2. Abrí una rama descriptiva.
3. Hacé un cambio pequeño y verificable.
4. Ejecutá `npm ci` y `npm run build`.
5. Abrí un pull request con la fuente oficial y una explicación del cambio.

## Cambios de datos

- Conservá las claves numéricas existentes.
- No renumerés provincias, cantones o distritos sin una fuente oficial.
- Adjuntá el enlace a la publicación oficial que respalda el cambio.
- Verificá que todos los archivos JSON sean válidos.

## Cambios de interfaz

La aplicación publicada es HTML, CSS y JavaScript estático dentro de `public/`. Probá los cambios en escritorio y móvil y no cambiés las URLs públicas de la API.

## Revisión

Los mantenedores revisan y fusionan los pull requests. Las contribuciones se publican bajo la licencia MIT del proyecto.
